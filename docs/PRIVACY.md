# Privacy, consent and public release

## Authorization statement

The project owner states that this was a test project and that authorization was obtained from everyone involved. This statement is reproduced with attribution; the work sample does not assert independent verification of consent or institutional ethics approval. Authorization does not require publishing participants’ identities or original records.

## Included in the public repository

- Synthetic steps, activity durations, seven-day histories and reference scores.
- Presentation screenshots and a product cover image.
- Selected UI source and a screenshot renderer excerpt.
- Public project credits include the owner-authorized abbreviated names: author D. Sangji and collaborator M. Cen. Existing GitHub account credits are retained: @Hawever-renbo, @Mark751127 and @marcmliu.

## Excluded

The original archive, slide deck and manifest are retained locally under the Git-ignored `original/` folder. They are not published. This avoids publishing an unaudited presentation container or retaining a manifest that no longer describes the sanitized publication.

No personal test records, participant names or contacts, consent forms, API keys, signing material, app configuration, private server URLs, production database, notification credentials or application documents are included in the public publication set. The historical filesystem paths in the renderer have been replaced by local relative paths or environment-variable configuration. Public screenshots remain the supplied synthetic presentation assets.

## Demo behavior

The interactive page changes local screenshot state. It does not capture or store health data, send check-ins or feedback, place calls, contact a production backend, use cookies/local storage, or load tracking scripts. The original bilingual preview also switches local images only. GitHub Pages may retain standard host access logs; a static site should not be described as leaving no server logs.

The Flutter excerpts are source for review, not executable website code. One widget contains application feedback-request logic referencing configuration that is not included. The browser never imports or executes Dart code. The renderer is not advertised as standalone or safe to connect to a production backend.

## Interpretation

Displayed numbers are uncalibrated research estimates. They are not clinical diagnoses or calibrated probabilities. The public data is synthetic and does not support claims of clinical efficacy.
